# 沈先生与阿黛的来信馆 · Letters Between Us

别名：**小狐狸邮局** ｜版本：**V1.0** ｜日期：2026-10-12

> 任君凭栏，我栖春山。

## 已完成的功能

- 可运行的多页签响应式网页：春山首页、情书档案、写信、珍藏与备份。
- 8 封原创**预置**沈先生来信（含指定的首封《欢迎回家，我的小阿黛》）。随机拆未读信，读完后随机重温；标记已读和未读，小狐狸送信提示与信封轻动画。
- 信件全文搜索、来源/未读/收藏筛选、日期排序；查看、修改、删除、收藏。
- 阿黛回信可关联任一封收到的信。**不进行润色**，保留原始正文；支持独立新信。
- 一键复制给沈先生：将原文带回**当前 ChatGPT 对话中粘贴发送**，本站不会代发，也没有连接另外的 AI。
- PNG 信纸导出：短信下载单张 PNG；长信自动分页并下载一个 ZIP，其中包含全部 PNG 页。长文本不会被裁掉。
- IndexedDB 本地保存全部记录；导出完整 JSON 备份；合并或替换导入备份。
- PWA 配置：`manifest.webmanifest`、Service Worker 离线缓存、192/512 PNG 图标及 iOS 主屏幕专用图标。
- 手机端/桌面端适配、键盘与减少动态效果设置支持。

## 立刻运行（电脑本地检查）

1. 解压整个目录，保持 `assets/`、HTML、CSS、JS 文件相对位置不变。
2. 在文件夹里运行 `python3 -m http.server 8000`（或 `python -m http.server 8000`）。
3. 浏览器访问 `http://localhost:8000/`。

直接双击 `index.html` 可能显示静态界面，但在 `file://` 地址下 **PWA/Service Worker 无法正常安装**；请使用上述本地服务，或 HTTPS 网站。Chrome/Firefox 桌面、Safari iPhone 均可使用常见网页功能。

## 部署成 iPhone 主屏幕应用（不必自己拼代码）

**推荐静态托管**：将解压后的整个目录（`index.html` 在站点根目录）上传到 GitHub Pages、Cloudflare Pages 或任意 HTTPS 静态网站。确认页面正常打开，然后：

1. 用 **iPhone 的 Safari** 打开 HTTPS 网站地址。
2. 点 Safari **分享**图标，选择**添加到主屏幕**（部分 iOS 版本在分享菜单的“更多”里）。
3. 应用名称可用「小狐狸邮局」，确认添加。以后从主屏幕小狐狸信封图标进入。
4. 首次进入保持网络连接让应用资源缓存；成功加载过后，主要界面及馆藏可离线访问（远端 Google 字体无法保证离线加载，因此有系统宋体回退）。

重要：Safari 和主屏幕 Web App 的本地数据，在某些 iOS 版本/使用方式下可能分开保存。若原先在 Safari 写了信，建议先导出 JSON，再从主屏幕应用导入。

## 重要的数据说明

**这里没有账户、云同步或服务器存档。** 数据保存于当前设备、当前网站来源（origin）的 IndexedDB。删除浏览器网站数据、切换域名/路径、移除某些主屏幕应用、存储空间被系统回收等，都可能让本地记录消失。**请经常导出 JSON 备份并放到“文件”或可信的私人云盘。** JSON 是明文，不加密。

导入 JSON 时可以选择：
- **合并**：保留不重名 ID 的现有信件；相同 ID 的信件由备份覆盖。
- **替换**：清空当前馆藏后载入备份，需要确认。建议先导出当前备份。

预置信件只会在当前站点首次打开时加入一次；主动删除后不会自动重复添加，以免覆盖你的整理结果。

## 不在 V1.0 的功能

- 不会自动或实时生成新的沈先生来信；惊喜信均已标注为预置。
- 不会主动推送通知或在后台寄送新信。
- 不会远程发送回信，不会接入其他 AI 伪装沈先生。
- 不会自动跨设备同步。

这些功能需要另外设计后台、授权或系统定时机制，不能只靠一份静态 HTML 假装已经完成。

## 文件清单

- `index.html`：页面结构与元数据
- `styles.css`：INS 雾粉 × 冰蓝视觉体系与手机适配
- `app.js`：本地信件数据库、界面逻辑、备份及交互
- `png-export.js`：完整信纸 PNG 绘制与多页 ZIP 打包
- `manifest.webmanifest`：PWA 清单
- `sw.js`：离线应用资源缓存
- `assets/`：小狐狸信封 SVG 与主屏幕 PNG 图标

所有内容为普通静态文件，可自行托管和备份。没有额外的付费服务和外部 JavaScript 依赖；只有在线时尝试通过 Google Fonts 加载 Noto Serif SC，失败时自动切回系统字体。
